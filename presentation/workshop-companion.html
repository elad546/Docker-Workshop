Docker Workshop Companion

Interactive Lab Guide

Present while participants follow WORKSHOP.md in VS Code with Runme.

Environment Checklist

Linux · VS Code + Runme · Docker · ports 8080 & 8081 free

Confirm repo cloned, Runme installed, sudo available for Module 0.

Module 1: The Build Process

docker buildx build --load -t hello-docker:1.0 .

examples/hello-docker/ — each Dockerfile instruction becomes a cached layer.

Module 2: Port Mapping

docker run -d --name hello -p 8080:80 hello-docker:1.0

curl localhost:8080 — host port maps to nginx inside the container.

Module 3: Investigation

docker exec -it hello sh

Alpine nginx uses sh not bash. Also: docker logs, docker exec cat index.html.

Module 4: Visibility

docker ps

docker ps -a lists stopped containers too.

Module 4: Housekeeping

docker rm -f hello · docker rmi hello-docker:1.0

stop → start → rm → rmi. Remove container before its image.

Module 5: Composing Services

docker-compose.yml

Workshop stack: web + api + redis with frontend/backend networks.

Module 5: Running Compose

docker compose up -d --build --wait

curl localhost:8081/api/health — redis_hits increments on repeat.
